# Recreated player animation

64 newly generated frames across eight dedicated action sheets: Idle, Run, Jump, Fall, Land, Shoot, Hurt, Death. Each action has its own eight-frame sequence. All individual PNGs are 128×128 with feet at y112 and fixed body mask (45,32)–(83,112). Standing/reference frame height sets a common scale for its entire action. Frames are checked for clipping and repeated file hashes before project updates. Sources and prompts are preserved. Old player/player-v2 folders are retained for reference; active resources point here.
