# Location background artwork

Level 1 reuses the existing station background. Levels 2–8 were generated for the distinct-location campaign. These backgrounds are scenery; native GDevelop instances define all playable platforms and collision.

## 2 — cargo-warehouse

File: `2.png`

Create a wide 16:9 pixel-art background for a 2D side-view platform adventure Circuit Rescue. Location: a huge orbital cargo warehouse interior, stacked navy steel shipping containers, overhead cranes and rails, yellow hazard stripes, cyan barcode monitors, distant storage racks and hanging work lights. Cohesive charming detailed 16-bit pixel art matching navy/cyan/amber robot adventure. Strict orthographic side-view elevation, no isometric perspective. Background scenery only: no playable platforms in foreground, no ground collision strip, no characters, enemies, bosses, mecha, UI, text or logos. Keep the lower half dark and uncluttered so player sprites and real level geometry read clearly. Full-bleed illustration, crisp pixel edges, not 3D-rendered or painterly. Each location should look clearly distinct.
