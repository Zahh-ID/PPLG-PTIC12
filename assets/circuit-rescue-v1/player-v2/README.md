# Corrected small-robot frames

Re-extracted from the original robot sheet using the actual occupied frame bands, rather than equal-width cells. Detached muzzle effects belong to their correct shot frame. Every frame is 128×128 with feet at y112; the feet/body anchor sets horizontal alignment so firing effects cannot move the sprite sideways. Original player/ PNGs are preserved. Existing CR_player_* resource names point to these corrected files. See normalization.json for exact source rectangles and anchors.
