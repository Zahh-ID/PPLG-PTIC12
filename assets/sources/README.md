# Generated source art

Generated with the built-in image_gen tool. Prompts and file provenance are recorded in `generation.json`; the player prompt is also stored separately. These are original sci-fi source sheets, not validated runtime atlases.

The requested exact canvas/grid sizes were not reliably produced. Some subjects approach or cross nominal cell boundaries. UI components are not uniformly arranged, and terrain seams need checking. Do not import by assuming source pixels match the prompt's coordinates. Keep originals; derive exact-size, palette-limited exports with recorded crop rectangles and animation metadata, then visually inspect them at native scale.

The campaign scenario now takes priority over free-building assets. Further generation is paused until the mission's combat, enemies and fixed-puzzle asset list is finalized. Player logical frames are 32x64. Enemy/combat additions and radio portraits are still missing. See `docs/campaign-scenario.md`.
